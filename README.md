# cimp-practices

This repository contains **optional practices, templates, and patterns**
for applying the CIMP canon in real systems.

This repository is **not part of the CIMP canon**.

It exists to reduce friction, not to enforce process.

---

## Relationship to the canon

The CIMP canon defines:
- concepts
- boundaries
- invariants
- governance principles

This repository provides:
- example forms
- practical heuristics
- reusable templates

If a practice conflicts with the canon,  
**the canon always wins**.

---

## What this repository is

- a toolbox for teams applying CIMP
- a collection of minimal templates
- a place for experience-driven guidance

---

## What this repository is not

- a mandatory process
- an official workflow
- a certification standard
- a replacement for judgment

Practices may evolve or be removed.

The canon does not.

---

## Structure

- `templates/` — minimal document templates (one possible form)
- `practices/` — short guides based on real usage

---

## Status

This repository evolves independently.

Breaking changes here do **not** imply changes to the CIMP canon.
