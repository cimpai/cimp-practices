# Practices

This directory contains short, experience-based guides
for applying CIMP concepts in real situations.

Practices are:
- optional
- adaptable
- context-dependent

They are not exhaustive and may change over time.

## Available Practices

- **[Writing Intent](./writing-intent.md)** — How to write falsifiable, outcome-oriented Intent
- **[Defining Scope](./defining-scope.md)** — How to set clear boundaries for Changes

- **[Kill Criteria](./kill-criteria.md)** — How to define stop conditions for Changes
- **[Recording Decisions](./recording-decisions.md)** — How to document explicit commitments

### Execution

- **[Execution Plan](./execution-plan.md)** — How to break down Changes into verifiable steps
- **[Observation Plan](./observation-plan.md)** — How to observe Changes after execution

## Using Practices

These practices are **guidelines, not rules**.

Adapt them to your context:
- Use what works
- Skip what doesn't
- Modify as needed

The canon defines concepts.  
These practices help apply them.
